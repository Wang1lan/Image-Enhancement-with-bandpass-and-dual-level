# 双尺度带通图像增强

基于 MATLAB 的 RGB 图像纹理增强示例：从原图独立提取细尺度和中尺度 DoG 带通细节，并使用双尺度软亮斑掩码抑制高光区域的额外增强。示例同时提供纹理/高光评价、手动 ROI 的 PCA 噪声评价和图像对比显示。

## 版本组织

| 目录 | 内容 | 状态 |
| --- | --- | --- |
| [`floating_point/`](floating_point/) | 当前浮点算法实现及运行说明 | 已提供 |
| `fixed_point/` | 后续定点实现 | 计划加入，当前未创建 |

“浮点版本”按整体算法实现分类，并不表示每个辅助函数都使用浮点运算。已有整数运算的辅助函数（例如 `gaussian5x5Fix.m`）保持原样，属于当前完整处理链的一部分。

## 开始使用

运行环境为 MATLAB R2022a 和 Image Processing Toolbox。请按 [浮点版本运行说明](floating_point/README.md) 准备自己的 RGB uint8 图像、配置图像路径，并在 `floating_point/` 目录运行 `demo.m`。

本仓库目前仅包含该示例及其依赖源码和说明，不包含演示图像、实验结果、测试文件或其他实验分支。
